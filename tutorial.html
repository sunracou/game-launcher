Game Launcher Debian/Ubuntu

Un guide simple pour installer, configurer et lancer vos jeux Windows sous Linux grâce à Wine.

Ce tutoriel présente les principales fonctionnalités du launcher et explique les opérations courantes, étape par étape.

➕ Ajouter un jeu ▶️ Lancer ▦ Affichage ⚙️ Organiser 🍷 Outils Wine 📁 Installer

Premiers pas

Le Game Launcher permet de regrouper vos jeux Windows et Linux dans une bibliothèque graphique et de les lancer avec la configuration Wine associée.

📚

Une bibliothèque centralisée

Retrouvez vos jeux au même endroit avec leur nom, leur image et leur description.

⚙️

Une configuration par jeu

Chaque entrée peut disposer de ses propres paramètres de lancement et de son propre environnement Wine.

▶️

Lancement rapide

Le bouton Run permet de démarrer directement le jeu sélectionné.

▦

Deux présentations

Utilisez la vue Grid pour les jaquettes ou la vue List pour une bibliothèque plus compacte.

Ajouter un jeu

La première étape consiste à créer une entrée dans votre bibliothèque à partir de l'exécutable du jeu.

1

Ouvrir l'ajout d'un jeu

Depuis le launcher, utilisez le bouton + Add, permettant d'ajouter une nouvelle entrée à la bibliothèque.

2

Sélectionner l'exécutable

Choisissez le fichier .exe correspondant au jeu. Il est possible d'éditer la commande de lancement.

3

Renseigner les informations

Donnez un nom au jeu. Ajoutez ensuite une image et une description si ces champs sont disponibles.

4

Enregistrer

Validez pour faire apparaître le jeu dans la bibliothèque.

Lancer un jeu

Lorsque la configuration est prête, le lancement est volontairement simple.

1

Sélectionner le jeu

Choisissez l'entrée correspondante dans votre bibliothèque.

2

Cliquer sur Run

Le launcher utilise les paramètres enregistrés pour démarrer l'exécutable avec Wine.

Les modes d'affichage

Le launcher propose deux façons principales de parcourir votre bibliothèque.

▦ Vue Grid

La vue Grid met davantage l'accent sur les images et les jaquettes. Elle convient particulièrement aux bibliothèques où l'identification visuelle est importante.

☰ Vue List

La vue List affiche les jeux sous forme de lignes compactes. Elle permet de voir davantage d'informations tout en conservant un accès direct au bouton Run.

Gérer la bibliothèque

Une bibliothèque reste facile à maintenir si chaque jeu possède des informations claires et une configuration cohérente.

✏️ Modifier

Utilisez l'édition d'une entrée pour corriger le nom, l'image, la description ou les paramètres de lancement.

🗑️ Supprimer

Supprimez une entrée lorsque vous ne souhaitez plus la conserver dans la bibliothèque.

🖼️ Images

Privilégiez des images suffisamment grandes et lisibles afin que les jaquettes restent agréables dans les deux modes d'affichage.

📝 Descriptions

Une courte description est généralement préférable à un long texte : elle laisse davantage de place aux informations essentielles et au bouton Run.

À retenirSupprimer une entrée du launcher ne supprime pas les fichiers du jeu.
Données du Game Launcher

Les fichiers de sauvegarde et les données du Game Launcher sont enregistrés dans le dossier de configuration de l'utilisateur

~/.config/game-launcher

Pensez à conserver une copie de ~/.config/game-launcher avant une réinstallation ou un changement important.

Wine Tools

Le Game Launcher Debian intègre un bouton Wine Tools qui permet d'accéder rapidement à plusieurs outils Wine liés au préfixe du jeu.

⚙️ Winecfg

Ouvre la configuration graphique de Wine pour modifier les paramètres de l'environnement Windows.

🧰 Winetricks

Permet d'installer ou de gérer certains composants, bibliothèques et réglages utiles au fonctionnement des jeux.

🗑️ Wine Uninstaller

Ouvre l'outil de désinstallation des programmes Windows installés dans le préfixe.

📋 Registre

Ouvre l'éditeur du registre Windows du préfixe Wine sélectionné.

📁 File Explorer

Ouvre l'explorateur de fichiers Windows dans le préfixe afin de parcourir son contenu.

📊 Task Manager

Ouvre le gestionnaire des tâches Windows pour consulter et gérer les processus exécutés dans le préfixe.

À savoirLes outils Wine sont lancés dans le contexte du préfixe associé au jeu. Cela permet de modifier ou diagnostiquer directement l'environnement utilisé par ce jeu.

Bonnes pratiques

📁 Organiser

Regroupez vos préfixes et vos jeux dans une arborescence claire et facilement sauvegardable.

💾 Sauvegarder

Conservez une copie de vos configurations et sauvegardes importantes avant les changements majeurs.

🧪 Tester progressivement

Ne modifiez pas plusieurs paramètres à la fois. Un seul changement facilite le diagnostic.

📋 Noter ce qui fonctionne

Pour les jeux complexes, notez le runner, le préfixe et les options qui donnent de bons résultats.

AstuceUtilisez des noms courts et cohérents. Par exemple : Game Title plutôt qu'un nom de fichier très long.
AttentionUne modification du préfixe ou du runner peut changer le comportement du jeu. Si une configuration fonctionne, gardez une copie de vos paramètres avant de faire des essais.

Wine et préfixes

Wine fournit la couche de compatibilité permettant d'exécuter des applications Windows sous Linux. Un préfixe Wine constitue un environnement séparé contenant notamment la configuration et les composants Windows du jeu.

Pourquoi utiliser un préfixe séparé ?

  • Éviter qu'un réglage d'un jeu perturbe un autre jeu.
  • Conserver des configurations différentes selon les besoins.
  • Faciliter les tests avec différentes versions de Wine.
  • Pouvoir repartir d'un environnement propre en cas de problème.
Bonne pratiqueLorsque cela est possible, utilisez un préfixe dédié pour les jeux qui ont des exigences particulières.

Exemple de structure

~/Games/
├── jeu-1/
│   └── prefix-wine/
├── jeu-2/
│   └── prefix-wine/
└── jeu-3/
    └── prefix-wine/
AttentionNe supprimez pas manuellement un préfixe Wine sans savoir ce qu'il contient : il peut renfermer les sauvegardes, réglages ou composants nécessaires au fonctionnement du jeu.

Dépannage

Vérifier la compatibilité

  1. Visitez la base de données de WinHQ pour avoir les informations sur la compatibilité des applications.
    2. winehq.org

Le jeu ne démarre pas

  1. Vérifiez que l'exécutable sélectionné existe toujours.
  2. Vérifiez le runner / la version de Wine utilisée.
  3. Vérifiez que le préfixe Wine est accessible.
  4. Essayez de lancer le jeu depuis un terminal pour obtenir davantage d'informations.

Le jeu démarre puis se ferme

Ce comportement peut provenir d'une dépendance manquante, d'un problème de configuration Wine ou d'une incompatibilité avec la version utilisée.

Écran noir ou affichage incorrect

Testez une autre version de Wine, vérifiez les paramètres graphiques du jeu et, si votre configuration le permet, comparez le comportement avec un préfixe propre.

Impossible de retrouver un jeu

Vérifiez le chemin du fichier .exe et assurez-vous que le disque ou le dossier contenant le jeu est toujours monté et accessible.

DiagnosticLorsqu'un problème apparaît après une modification, revenez en priorité au dernier réglage qui fonctionnait. Cela permet d'isoler plus facilement la cause.

Raccourcis

Installer

Depuis un terminal, vérifier les dépendances

sudo apt update
sudo apt install python3 python3-gi gir1.2-gtk-3.0

Si vous souhaitez vérifier et installer WineHQ

wine --version
sudo apt install winehq-stable

Depuis le dossier d'installation

chmod +x install.sh
./install.sh

Pour désinstaller

chmod +x uninstall.sh
./uninstall.sh
